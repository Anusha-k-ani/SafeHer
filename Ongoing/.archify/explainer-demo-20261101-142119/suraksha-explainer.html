How do we demonstrate SurakshaSetu?

Long image

A

Answer

Show the local web app, then Module 1 analysis. Citizens save reports and Risk Alerts to a JSON file. The pipeline clusters them. This demo does not call 112.

  1. Sign in as citizen / suraksha-demo before you file anything.
  2. The store is an in-app record, not a police FIR.
  3. Hotspots need 3 points in a 0.01 degree cell. Empty cells are not safe.

Applies toLocal demo on 127.0.0.1:3000. HMAC accounts. No 112 dispatch.

  1. Open localhost ↗

    Run npm run dev in Ongoing/web. Open 127.0.0.1:3000.

  2. Citizen login ↗

    Username citizen, password suraksha-demo.

  3. File a report ↗

    Use Report an Incident. Add GPS if the browser allows it.

  4. Two-press alert ↗

    Press Risk Alert once, then again within 3 seconds.

  5. Safety map ↗

    Say the overlay is labelled demo until a reviewer verifies rows.

  6. Authority review ↗

    Log out. Sign in as supervisor / suraksha-demo.
