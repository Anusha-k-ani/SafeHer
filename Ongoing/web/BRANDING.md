# SurakshaSetu branding

Academic title, unchanged:

**Incident Analysis and Hotspot Identification for Security Provision against Women Harassment in Public Spaces.**

Application name: **SurakshaSetu**. Tagline: **Connecting Streets. Protecting Lives.**

Suraksha means safety. Setu means a bridge. The mark is a road line under a bridge arch: citizens on one side, police and municipal teams on the other.

This logo was drawn for this project as original SVG. Trademark availability was not checked.
