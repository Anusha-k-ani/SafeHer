# SurakshaSetu web app

Citizen and authority UI. Start here:

```bash
npm install
npm run dev
```

Open http://127.0.0.1:3000  
Login: `citizen` / `suraksha-demo`

Full project README: [../../README.md](../../README.md)

The operational store is `data/suraksha-store.json` (gitignored). This app does not call 112.
