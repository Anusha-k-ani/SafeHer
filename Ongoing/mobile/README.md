# SafeHer Mobile (Expo)

Women's street safety reporter for Bengaluru.

## Run

```bash
cp .env.example .env
# Set EXPO_PUBLIC_SUPABASE_URL and EXPO_PUBLIC_SUPABASE_ANON_KEY
npm install
npx expo start
```

## Tabs

- **Home** — detects GPS area + community verdict + global KPIs
- **Report** — Safe/Unsafe form with factor chips
- **Map** — live community report markers + area circles
